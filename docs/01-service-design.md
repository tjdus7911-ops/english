# 혼자영어 — 서비스 설계 (IA · 사용자 플로우 · 화면 목록 · 기능정의)

> 핵심 콘셉트: "혼자 공부해도 다음에 무엇을 공부해야 하는지 알려주는 영어 독학 앱"
> 대상: CEFR A1~B2 (레벨은 앱 내부 추정 기준이며 공인 인증이 아님)

## 1. IA (정보 구조)

하단 내비게이션 5개 탭 + 몰입형(내비게이션 숨김) 학습 화면.

```
홈 (/home)
├─ 오늘의 복습 카드 → 복습 (/review)            [몰입형]
├─ 오늘의 추천(학습량 조절) → MY 설정 / 취약 개념 연습
├─ 오늘의 신규 학습 → DAY 학습 (/course/lesson/:id) [몰입형]
├─ 학습 진도 · 이어서 공부하기
├─ 알림함 (/notifications)
└─ 자유학습 바로가기

학습코스 (/course?level=)
├─ 레벨 탭 A1·A2·B1·B2 (각 5~6개 대단원, 대표 단원 1개 '학습 가능', 나머지 '콘텐츠 준비 중')
└─ 단원 상세 (/course/unit/:id)
   ├─ DAY 1·2 (순차 해제)
   ├─ 건너뛰기 테스트 (/course/skip/:id) [몰입형]
   └─ 단원 단어장 · 문법 강의 바로가기

자유학습 (/free?level=)
├─ 오늘의 단어 (/free/word-study) [몰입형] — 하루 목표 개수 조정
├─ 단어장 (/free/words) → 단어 상세 (/free/words/:id)
├─ 단어 퀴즈 (/free/word-quiz) [몰입형]
├─ 문법 단원 (/free/grammar) → 문법 강의 (/grammar/:id)
│   └─ 확인 문제 · 영작 · 마무리 테스트 (/practice?concept=&mode=check) [몰입형]
├─ 유형별 문제 (/practice?level=&type=) [몰입형]
└─ 저장한 단어 · 오답노트 (/wrong-notes)

실력분석 (/stats)
└─ 학습 요약 · 장기 기억 현황 · 영역별 실력 지도 · 문법 세부 영역 · 취약 개념 · 개념별 상태 · 복습 유형별 정답률 · 14일 추이 · 학습 기록

MY (/my)
├─ 학습 설정 (레벨, 하루 시간, 신규 단어 목표, 복습 사용·하루 복습량)
├─ 알림 설정 (수신 동의, 시간, 종류 4가지)
├─ 레벨 테스트 다시 보기 (/placement) · 저장한 단어 · 온보딩 다시 하기
└─ 콘텐츠 안내 · 학습 기록 초기화
```

### 뒤로가기 규칙
- 헤더 뒤로 버튼: 앱 내 히스토리가 있으면 이전 화면, 직접 진입(새 탭·새로고침)이면 상위 화면으로 이동.
- 몰입형 학습 화면에서 뒤로: "그만둘까요?" 확인 모달 (푼 답안은 이미 저장됨).
- 결과 화면에서 뒤로: 상위 화면으로 `replace` 이동해 결과 화면이 히스토리에 다시 남지 않게 함.

## 2. 사용자 플로우

### 2.1 첫 실행
온보딩(소개 → 목적 → 하루 시간 → 자가 레벨) → 레벨 테스트(18문항) 또는 건너뛰기 → 결과(어휘·문법 레벨 개별, 추천 = 낮은 쪽) → 코스 레벨 선택 → 홈

### 2.2 매일 학습 (복습 우선)
1. 홈 상단 **오늘의 복습**: 영단어 수 / 문법 수 / 완료율 / 예상 시간 → [복습 시작] 또는 [나중에]
2. 복습 풀이 → 항목별 다음 복습일·기억 상태 → "오늘 복습을 모두 완료했어요! 이제 새로운 영어를 배워볼까요?"
3. **오늘의 신규 학습** (DAY): (남은 복습, 건너뛰기 가능) → 신규 단어 → (30분 코스: 단어 퀴즈) → 문법 강의 → 어휘 연습 → 단계별 연습(확인 문제) → **이해도 판정** → 직접 영작 → 마무리 테스트 → 완료
4. 복습을 미뤄도 신규 학습은 막지 않음.

### 2.3 이해도 기반 진행 (문법)
| 확인 문제 결과 | 판정 | 다음 행동 |
|---|---|---|
| 정답률 ≥ 80% & 같은 오답 유형 반복 없음 | 이해 완료 | 개념 학습 완료 기록 → 다음 학습 |
| 40% ≤ 정답률 < 80% | 일부 오답 | 같은 개념 변형 문항으로 추가 연습 → 재판정 |
| 정답률 < 40% 또는 같은 오답 유형 2회 이상 | 기초 필요 | 쉬운 설명·선행 개념 → 확인 문제 재도전 (개념은 미완료 유지) |

### 2.4 오답 → 복습
오답 → 오답노트 자동 저장(원인 유형 + 해설) + 관련 개념 복습 항목을 오늘 복습 대상으로 → 복습 시 **다른 문장(변형 문항)**·다른 유형으로 재시험 → 오답노트에서 다시 풀기/복습 완료 처리

### 2.5 알림
설정 시간 이후 앱을 열면 알림 후보 계산 → 새 알림은 알림함 + 상단 배너 → 선택 시 해당 복습 화면(`/review?focus=…` 등)으로 이동
