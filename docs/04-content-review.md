## 자동 검증 (`src/lib/content.test.ts`) — 통과

- ID 중복 없음, 최소 분량(단어 80·문항 60) 충족
- 모든 정답·허용 답안이 채점 로직에서 정답 처리됨
- 객관식: 보기 4개, 정답 포함, 보기 중복 없음, 보기별 오답 이유가 실제 보기와 일치
- 단어 배열: 토큰을 이으면 정답 / 오류 찾기: 정답 인덱스 유효 / 빈칸: `___` 존재
- 단어·개념·변형 원문항 참조 무결성, 변형 문항은 원문항과 다른 문장
- 같은 문장 중복 출제 없음
- 문법 강의 10단계 데이터 존재, 문장 분석 조각 = 원문, 선행 개념 유효
- 단어 예문 빈칸 문항: 빈칸을 정답으로 채우면 원래 예문과 일치

## 작성자 검수 (자체)

- 예문·해설은 직접 작성했고, 타 서비스 유료 콘텐츠를 복제하지 않았다.
- 오답 보기는 실제 학습자 오개념(수일치, to/-ing 혼동, 현재완료+과거 시점, If절 would 등)을 반영했다.
- 문법적으로 맞을 수 있는 다른 답이 있는 문항은 허용 답안을 추가했다 (예: a2-q07, b1-q07, b2-q12 could/might).
