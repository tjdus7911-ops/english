## 3. 기존 시스템 연동

| 연동 | 동작 |
|---|---|
| 학습 기록 | 연습 문제 답안·세션 시간 저장 (`answers`, `sessions`) |
| 오답노트 | 표현 문제 오답 자동 저장, 듣기 탭 분류 |
| 자동 복습 | 표현 항목(`x:`) — 저장하거나 틀리면 등록, 복습 때마다 듣고 빈칸 → 뜻 → 응용 배열로 유형 변경 |
| 취약 개념 분석 | 연결 문법이 있는 표현 문항은 해당 개념 정답률에 반영 |
| 홈 오늘의 복습 | '문법·표현' 수에 포함 |
| 학습 완료 | 표현별 완료 이벤트 `expr:<id>`를 **한 번만** 기록 (`completionEvents`) |
| 캐릭터 성장 경험치 · 영어 마을 보상 | **이번 범위에서 제외** (사용자 결정). 위 완료 이벤트 기록이 향후 보상 지급의 중복 방지 기준이 됩니다 |
